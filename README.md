# 钢铁坦克大战 🎮

一个纯 HTML + Canvas 编写的单人坦克对战小游戏，单文件即可运行，无需任何依赖或构建步骤。

## 运行方式

直接用浏览器打开 `index.html` 即可开始游戏。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动坦克 |
| 鼠标 | 瞄准炮口方向 |
| `空格` / 鼠标左键 | 开火 |
| `P` / `Esc` | 暂停 / 继续 |
| `回车` / 点击画面 | 开始 / 重新开始 |

## 玩法特性

- **波次战斗**：消灭全部敌坦克后进入下一波，波次越高敌人越多、越快。
- **可破坏地形**：砖墙可被炮火摧毁，钢墙不可摧毁，用于寻找掩体或制造缺口。
- **强化道具**：击毁敌坦克有概率掉落，包括——
  - 🛡 护盾（短暂无敌）
  - ⚡ 连射（提高射速）
  - 🔱 三连（一次发射三发炮弹）
  - 💨 加速（提升移动速度）
  - ❤ 生命（增加一条命）
- **粒子特效 & 音效**：爆炸、火花、屏幕震动，以及基于 Web Audio 的合成音效。

## 技术说明

- 纯原生 JavaScript，无第三方库。
- 使用 Canvas 2D 渲染，`requestAnimationFrame` 驱动游戏循环。
- 砖墙 / 钢墙采用瓦片网格碰撞检测，坦克采用分轴（X/Y）移动碰撞处理。
